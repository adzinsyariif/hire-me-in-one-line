## How it works

`main.ts` (Node 22, stdlib only) writes that sentence deterministically to `/output/entry.txt`:

```sh
node main.ts            # writes /output/entry.txt
node main.ts <outDir>   # writes <outDir>/entry.txt (for local verification)
```
